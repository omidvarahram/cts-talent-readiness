# @cts-talent/ui

Reusable React Native presentation components for Talent Readiness.

## Rules

- Controlled values and callbacks only
- No data fetching and no employee policy
- Minimum touch target 48px; login buttons use `login` prop for 54px height
- `SideDrawer` supports backdrop dismiss and focus-on-open refs
- `StatusBadge` tones: approved / pending / rejected

## Usage

```tsx
import { ThemeProvider, Button, SideDrawer } from '@cts-talent/ui';
```
